# 冻结模型在第二批100套处方上的一次性独立测试

## 结论

冻结主模型 `RF/raw9, leaf=1` 在第二批的总体 MAE 为 **34.02**、RMSE 为 **83.53**、R² 为 **0.517**。它明显优于规则条件 Dummy，并小幅优于冻结对照 `RF/raw9, leaf=3`。模型身份不因本次测试结果改变，Stage-Aware 仍只保留为探索性机制实验。

## 冻结与无泄漏执行

- 冻结清单在读取第二批优化目标前写入，SHA-256 在评估前后保持一致。
- 训练仅使用 case 1–100 的300个规则条件样本。
- 测试仅使用 case 101–200 的300个规则条件样本。
- 模型全部拟合完成后才读取第二批 `final_working_f_number`。
- 第二批标签未用于预处理、特征选择、超参数选择、阈值设定、重拟合或模型替换。
- 本次只执行一次测试，未运行新的 Zemax 优化。

## 独立性及协议核查

- 训练/测试处方指纹重叠：0；原始五参数精确重叠：0。
- 第二批是同一确定性伪随机采样流的后续区段，而不是重新播种得到的独立随机实现。因此更准确的表述是“未参与训练的、处方不重叠的顺序留出集”。
- 采样范围、采样策略、九个特征的名称/顺序/定义/单位完全一致。
- Rule 1–3、核心优化代码哈希、运行时策略、执行源、组超时均一致。
- `background_batch.py` 与 `background_model_worker.py` 的包装层哈希不同；这属于此前状态写入/调度基础设施修改。核心优化器哈希及冻结运行参数未变化，因此未发现其改变光学优化协议的证据。
- 采样过程没有声明十进制定量精度，故没有自行添加“近似重复”阈值；按原始序列化浮点精度进行逐参数精确核查。

## 解释边界

主模型确实学习到了超出规则均值的处方信息，但独立测试误差仍主要由 Rule 2 和 F/#=500 长尾主导。非500子集 R² 为负，原因是该子集目标方差较小，而绝对误差仍不为零；这不应被解释为主模型比总体常数基线更差，因为该 R² 是在事后定义的非500子集内部重新计算的。

本次结果不得用于回头选择 leaf、修改特征或调整超参数。任何下一版模型必须另立研究阶段，并使用新的验证策略或第三批未触碰测试数据。
