# V2 OOF误差机制与规则决策可行性

## 结论

V2的OOF结果支持“规则排序具有一定可预测性”，但尚不支持宣称规则决策能够提高共同目标成功率。建议**暂不直接启动常规100套第三批正式验证**；先冻结规则效用函数和验证终点。如果研究目标接受“降低距目标缺口”而不是“提高达标率”，则第三批验证有必要，但按当前稀疏收益估计，100套很可能只能提供探索性证据。

所有选择均使用按处方分组得到的OOF预测。真实三规则终点只在选择完成后用于评分，没有训练新的选择器，也没有运行Zemax。

## 误差机制

### F/#

- 总体MAE 26.09，但中位绝对误差仅6.41，说明均值被长尾主导。
- 31个F/#=500端点的MAE为176.27，且全部被低估；非500端点MAE为17.91。
- 这31个端点全部对应Rule 2未进入孔径阶段，停止签名为 `field=step_limit; aperture=not_started_first_stage_limit`。
- Rule 2的F/# MAE为52.29，显著高于Rule 1的16.30和Rule 3的9.68。
- F/#绝对误差与 `thin_power_1_per_mm`、`object_l1_mm` 的探索性Spearman相关均约为−0.425，与 `thin_spacing_mm` 为0.354。它们提示困难区域，但未经过独立确认，不能据此修改特征或模型。

### 最大视场

- 总体MAE 0.357°，中位绝对误差0.075°，p90为1.165°。
- Rule 1视场MAE为0.715°，而Rule 2/3分别为0.169°和0.187°；视场误差主要集中在Rule 1。
- F/#与视场绝对误差相关为0.469，说明困难处方往往同时影响两个目标，但带符号残差相关为−0.309，两个方向的偏差并不相同。

## 规则决策定义

为避免强制建立唯一“最佳规则”标签，使用固定的物理目标缺口：

`gap = max((F/# − 20)/20, 0) + max((5° − field)/5°, 0)`

每套处方根据三条规则的OOF预测选择gap最小的规则；真实gap只用于事后计算选择收益。并列时采用固定的最小规则编号，不使用真实终点拆分并列。

## 决策结果

| 指标 | 结果 |
|---|---:|
| 命中真实最优规则集合 | 75.0% |
| 所选规则属于真实Pareto集合 | 97.0% |
| 预测/真实Pareto集合平均Jaccard | 0.719 |
| 零regret比例 | 75.0% |
| 平均oracle regret | 0.158 |
| 所选规则实际达共同目标 | 21.5% |

选择次数：Rule 1为37套、Rule 2为21套、Rule 3为142套。

| 策略 | 平均gap | 中位gap | p90 gap | gap=0 |
|---|---:|---:|---:|---:|
| 固定Rule 1 | 1.323 | 0.840 | 4.216 | 17.5% |
| 固定Rule 2 | 4.255 | 0.552 | 24.149 | 21.5% |
| 固定Rule 3 | 0.881 | 0.535 | 1.723 | 21.5% |
| OOF预测选择 | **0.786** | 0.561 | **1.543** | 21.5% |
| Oracle | 0.628 | 0.494 | 1.362 | 22.5% |

相对最佳固定策略Rule 3，OOF选择平均gap降低0.095，即约10.8%。按处方配对bootstrap的95%区间为[−0.204, −0.015]。不过收益高度稀疏：200套中22套改善、166套相同、12套变差；单侧符号检验仅接近而未达到0.05水平（22/34，p≈0.061）。

共同目标成功率没有提高：预测选择和固定Rule 2/3均为21.5%，oracle上限也只有22.5%。因此当前决策价值主要是减少失败程度，而非把更多处方变为成功。

## 是否开展第三批

当前证据足以提出一个可独立检验的规则策略，但不足以支持立即把它作为生产决策器。建议：

1. 先冻结上述gap定义、OOF选择流程和“固定Rule 3”对照，不再用现有200套调整。
2. 第三批的主终点设为每套处方的 `gap(预测选择) − gap(Rule 3)`；成功率、Pareto命中率作为次要终点。
3. 当前配对差值标准差约0.699、均值效应约−0.095。简单正态近似下，双侧α=0.05、80%功效约需424套处方；由于数据零膨胀且长尾，该估计仅用于规划。
4. 若第三批仍只有100套，应明确定位为独立先导验证，不能预期对这一稀疏效应给出确定结论。

因此决策是：**先冻结第三批验证协议；不按普通100套批次直接开跑。接受“先导验证”定位后可以开展100套，若要一次形成确认性结论，应扩大样本或预设分阶段方案。**
