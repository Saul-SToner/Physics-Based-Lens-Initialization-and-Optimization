# Rule 2优化阶段切换最小可行性实验

## 机制审计

Case 1–200中共有31套Rule 2终点保持F/#=500。31/31日志均显示完全相同的机制：

- 先执行视场阶段；
- 视场阶段以 `step_limit` 结束；
- 孔径阶段标记为 `not_started_first_stage_limit`；
- 没有任何样本曾进入孔径阶段后又返回F/#=500。

因此，F/#=500在该集合中是阶段顺序与提前终止策略形成的删失边界，而不是孔径优化得到的最优值。

## 案例选择和干预

仅使用31套处方的优化前raw9特征，标准化后进行10类KMeans，并选各类medoid：Case 5、25、66、115、129、132、140、157、188、189。

干预从原Rule 2已验收终点加载镜片，在保持原视场不变的情况下继续孔径阶段。DLS仍为每次50循环、2核；MTF、几何、共轭、放大率和出瞳约束均沿用原引擎。失败尝试回载上一已验收终点。历史Rule 2和Rule 3直接作为对照，没有重跑。

- 阶段切换0/10更优，2/10相同，8/10更差。

## 物理验收

10个干预终点均通过原MTF和几何验收：最小MTF余量0.000122，最小几何余量0.315 mm。干预终点最大RMS点半径的均值为9.20 μm，Rule 3为10.35 μm。

共轭条件继续按原软约束处理。干预集合中的最大绝对残差为：物像B项0.0070 mm、放大率误差0.0100、出瞳B项0.650 mm。它们没有被新增为硬阈值，因此不能把“通过验收”解释为共轭残差严格为零。

## 结论

阶段切换在机制上可行：它能把大多数Rule 2的F/#=500策略边界转化为连续、物理验收通过的终点。但作为正式优化规则，它没有超过现有Rule 3：效果更差或相同，且平均墙钟成本更高。

因此不建议直接扩大该干预。若继续研究，合理方向不是简单强制切换，而是分析哪些初始处方能从切换获益、是否需要有限额外预算或在视场/孔径之间采用更早的交替策略。本实验不支持用Case 201以后数据调整该策略。
